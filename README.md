# CS-405 Secure Coding

This repository contains my coursework and programming projects completed for **CS-405: Secure Coding** at **Southern New Hampshire University (SNHU)**. Throughout this course, I applied secure software development principles, implemented secure coding practices in C++, and strengthened my understanding of identifying, preventing, and mitigating common software vulnerabilities.

## Repository Contents

### Module 1 – Numeric Overflow and Underflow
Implemented a C++ application demonstrating integer overflow and underflow, analyzed the associated security risks, and applied secure coding techniques to validate input and prevent arithmetic errors.

### Module 2 – SQL Injection
Developed a C++ application that demonstrates SQL injection vulnerabilities and implemented secure coding practices to mitigate injection attacks through proper input validation and safer programming techniques.

### Module 3 – Secure Coding Policy
Created a secure coding policy based on the **SEI CERT C++ Coding Standard**, outlining secure development practices, coding standards, and recommendations for producing secure and maintainable software.

### Module 4 – Exception Handling
Implemented structured exception handling using standard and custom C++ exceptions. The project demonstrates proper error handling, exception propagation, and safe program termination.

### Module 4 – Unit Testing
Developed automated unit tests using **Google Test (GoogleTest)** to verify application functionality and improve software reliability through repeatable testing.
